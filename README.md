## 📌 About This Repository

**Web Engineering Projects** is a collection of small frontend exercises and practical tasks completed throughout my Web Engineering coursework.

Instead of representing one large application, this repository documents my progress through multiple individual tasks. Each exercise focuses on practicing a particular aspect of frontend web development and gradually building a stronger understanding of how websites are structured and developed.

The repository currently contains **four practical HTML-based tasks**:

- Practice Task 1
- Practice Task 2
- Practice Task 3
- Practice Task 4

These projects serve as a record of my hands-on learning and experimentation with web technologies.

## 🎯 Learning Objectives

The main purpose of this repository is to strengthen practical knowledge of:

- Web page structure
