StudentCard Component (Plain JS Simulation) 
// Arrow function with destructuring in parameter
const StudentCard = ({ name, marks, course }) => `
  <div class='card'>
    <h3>${name}</h3>
    <p>Course: ${course}</p>
    <p>Marks: ${marks}</p>
  </div>
`;

// map() to render list — same pattern as React JSX
const html = students.map(s => StudentCard(s)).join('');
document.getElementById('output').innerHTML = html;

How It Works (Step by Step)
1

Define the Component Function

StudentCard is an arrow function that takes props object and destructures { name, marks, course } directly in the parameter.

2

Create Student Data Array

An array of 4+ student objects acts as mock data — same structure as API response or state in React.

3

Map Over Array

students.map(s => StudentCard(s)) calls the component for each student, returning HTML strings — identical to React's JSX rendering pattern.

4

Join & Inject

.join('') combines all HTML strings, then innerHTML injects them into the DOM — React uses ReactDOM.render() instead.

🔄 Plain JS → React Mapping
Component

Plain function returning HTML string → React function returning JSX

Props

Single object parameter → Same props object in React

Destructuring

{ name, marks } in params → Identical in React

List Render

.map() + .join() → .map() + key prop in JSX

Template

Template literal `<div>` → JSX syntax <div>

DOM Injection

innerHTML = html → ReactDOM.createRoot()
